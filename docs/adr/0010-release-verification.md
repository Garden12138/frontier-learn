# ADR 0010：有界发布验收

2026-10-26，推进已有 MVP 发布门槛，不增加产品功能。

- 公开页面兼容性为显式 opt-in、固定十个 arXiv/HF URL、每页 15 秒导航/25 秒总超时、
  最多 30 个请求、只读 GET。禁脚本/表单/图片/模型下载/第三方请求，不登录或绕过访问限制。
  不向模型发送页面。只保存 URL、时间、哈希、数量和失败状态，不将网页全文纳入 fixture。
  自动 DOM 定位不是 SC-003 的人工抽检；网络失败须如实记录，不能记为通过。
- 备份恢复使用测试 PostgreSQL 内新建的两个随机 `frontier_test_*` 数据库、合成账号/学习
  数据及临时加密密钥。pg_dump/pg_restore 实际执行，备份文件临时且权限 0600，结束清除。
  校验 schema head、内部学习记录/凭据恢复及原密码可登录，不对开发/生产库执行恢复覆盖。
  恢复环境先不启 Worker；外部写回/云处理保持关闭，未完成作业需要核对后再恢复。
- 本地性能测量使用生产构建、真实浏览器/HTTP/隔离 PG、合成已登录账号/计划。
  固定 5 次预热、30 次重复导航，报告从导航开始到任务可操作的 p50/p95/max 和失败数。
  仅本机串行、无 CPU/网络模拟，不能解释为标准网络或生产并发下的 p95；预算/真人质量
  仍须真实服务验收。测试耗时与请求/页面耗时分开记录。
