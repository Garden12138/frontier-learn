# ADR-0005 · 目标、计划版本与每日建议

Status: Accepted for MVP planning slice · 2026-10-25

## 决策

- 学习目标支持任意主题，不要求 GitHub。目标创建需幂等键，编辑使用完整 PUT 和
  goal version；计划生成同时检查 goal version 与当前 revision，冲突返回 409。
  每用户最多 30 个目标，每目标一份当前计划，最多 200 次追加修订、40 个当前任务。
- 规划先用可替换的本地规则完成可恢复路径，明确标为 LOCAL_RULES；不伪装成真实模型。
  无证据为 EXPLORE；笔记或自报为 CHECK；最新理解验证通过为 APPLY；最新失败或
  超过 30 天的通过记录为 REVIEW。证据仍需符合各阶段实际验证规则，不能以任务完成代替。
  真实模型语义编排与真实学习效果尚未验收，后续 Provider 接入须保留规则降级及独立云端授权。
- 最多 8 个优先方向，用户可指定至多 16 条方向先修关系；校验缺失节点、重复方向、
  循环与任务顺序。没有依据时不虚构真实技术先修；关系明确标为用户指定、尚未独立验证。
  长期方向、阶段步骤和今日任务有建议投入、理由与证据 ID。时间是建议投入，不是实际阅读时长承诺。
- 用户可拒绝自评，保持 UNKNOWN；自报与理由保存在目标快照，不直接改为验证过的知识状态。
  无存量来源也可生成计划。不会把完整原文发给模型，本阶段规划不调用外部付费 API。
- LearningPlanRevision 是只追加的结构化 JSON 快照；LearningTask 是当前投影且保留历史任务 ID。
  接受、暂停、恢复、跳过、重排、插入、完成、恢复旧版本均产生新修订；恢复不会覆盖原记录。
  用户完成/跳过的兴趣项在再规划时留在历史，未完成兴趣项保留在当前计划。
- 每目标设置每日预算和 IANA 时区；默认 UTC，Web 默认浏览器时区。TaskCompletion
  记录手工完成日期与建议分钟，每任务每日唯一；恢复旧版本也不重复累计。今日候选累计不超过
  该目标当日剩余预算，不推断跨目标共享的全部空闲时间。完成任务不生成已掌握证据。
- 生成和变更先拿用户级事务锁，再读取/锁定目标和计划，和证据写入保持一致。新验证可触发
  新一轮任务，保留前轮历史及完成记录。先修步骤被主动跳过不等于掌握，仍允许继续手动学习。
- 计划历史只保存证据 ID，不复制私密源文或原始来源路径。读取时按当前用户解析有效证据；
  来源删除/撤回后返回不可用标记，不继续显示已删除的引用。用户自选兴趣 URL 只允许 HTTPS，
  不自动请求，标为“用户提供、未验证”；实际导入仍走独立 URL 安全边界。
- 用户可确认删除目标及计划/任务历史，不影响独立知识来源与证据，不执行外部删除。

## 验证

真实隔离 PG 覆盖无知识库/拒绝自评、笔记与验证对路径的影响、目标并发、版本恢复、
先修错误、日预算、完成不等于掌握、引用撤回与跨用户访问；浏览器覆盖首次目标到可行动任务。
这些是开发验收，不代替 SC-002/SC-005 的真人使用与学习效果证据。
