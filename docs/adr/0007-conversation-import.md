# ADR-0007 · 分享对话作为待验证学习材料

Status: Accepted for MVP implementation · 2026-10-25

- 仅读取用户明确提交的 `https://chatgpt.com/share/<UUID>`，兼容旧
  `chat.openai.com/share/<UUID>`；禁止登录会话、私有接口、附件、查询参数和任意网页。
  分享可能只有单条回答，角色不足时保持 UNKNOWN，不补造用户问题。
  格式与访问限制依据：[OpenAI 分享说明](https://help.openai.com/en/articles/7925741-sharing-conversations-and-scheduled-tasks-in-chatgpt)。
- 沿用已验证的 IP 固定 HTTP Reader，保留原域名 TLS 校验；最多两次跳转，每跳重新检查
  主机、路径、同一分享 ID、DNS 和公网地址；不发送用户 Cookie、Authorization 或 Referer。
  HTML 总预算 1MB、总获取超时 20 秒，不执行页面 JavaScript，不绕过登录、反爬或访问控制。
- 解析已返回 HTML 中明确的 user/assistant 消息节点。脚本、表单和隐藏节点跳过；页面
  只提供需执行的 hydration 脚本时保留解析失败，提供粘贴回退，不把任意 JSON 当作对话。
  角色是材料内标签，不能证明作者身份或答案真实性。手工文本使用行首角色标签；代码围栏内
  的角色文字不改变归属；无法识别的内容标 UNKNOWN。代码始终以文本显示。
- 确认前先在 Web 预览待提交的文本或链接，并提醒移除敏感内容。明确同意后才保存到当前
  用户的个人学习库，使用本地解析，不发送外部模型。每份材料最多 30,000 字符、40 条消息，
  有界分段；超限安全失败，不静默丢弃。API 错误、审计和任务日志不包含正文或分享 URL。
- ConversationImport 保存原始手工材料及解析快照，关联只含 import ID 的有界 Job。
  取消/删除撤销租约；失败保留状态，允许有限重试或新建手工回退；不覆盖已有成功材料。
  三次尝试、30 秒执行、五分钟截止；创建按用户和 Idempotency-Key 幂等。
- 本地规则从用户问题或助手待核实主张生成 1–3 个候选问题，逐条指向消息/片段快照，
  匹配当前用户已有知识线索。AI 回答和导入行为均不创建 KnowledgeEvidence 或提高掌握度。
- 用户可明确加入目标的当前计划或拒绝候选，使用会话版本及计划修订校验，并发不静默覆盖。
  计划中仅保存通用验证步骤和材料 ID，不复制私人对话原文；打开材料才解析当前有效来源。
  删除材料后旧计划的来源显示不可用，历史版本无需继续保留敏感原文。
- 内部删除移除材料、候选与关联任务，不删除外部分享页、已有计划或独立知识证据。
  正式身份、真实分享页兼容性和模型语义提炼保持发布门槛，合成测试不冒充真实在线成功。
- 成功提交后清空 Web 输入框；失败/取消的手工材料可由拥有者恢复原始文本重新编辑，
  正常成功响应不重复携带原始粘贴全文。历史同步显示任务状态，失败不伪装仍在加载。
- `0006_conversation` 回退时清理所有计划任务快照中的新增 `conversation_ref`，避免旧版
  strict DTO 拒绝读取；仅移除来源元数据，保留任务/顺序/修订。已导入材料及引用元数据需要备份恢复。
