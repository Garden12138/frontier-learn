# ADR-0013 · 本地试用的跨端退出与运行地址

日期：2026-11-08。范围：现有 US3/US6 会话隔离与 V0.1.1 试用准备，不增加功能。

真实 Chromium/MV3 连接日常服务时复现：插件以 Bearer 退出后，服务端无条件返回删除
`frontier_session` 的 Set-Cookie，使同主机另一端口的 Web Cookie 被清除。数据库原本只
撤销当前会话，因此修正响应：Bearer 注销仅撤销该 Bearer 会话，不发送 Set-Cookie；
Cookie 注销才清理 Web Cookie。账号恢复仍按已有规则撤销所有旧会话。无数据库变更。

本次 Mac 的 5432/5173 已被其他项目使用，日常试用固定 DB 55433、API 18000、Web 5176，
API/Web 同为 `127.0.0.1`。`infra/local-trial.env.example` 为无密钥配置，复制到被忽略的
`.env.trial`，不覆盖既有文件。Mock、写回、云模型保持关闭。Chrome 插件最终构建为 18000。
API/包/插件现有版本标签仍是 0.1.0，V0.1.1 是此次质量验收批次，不据版本标签判定迁移。

Docker DNS 的非公网 IPv6 触发 UNSAFE_URL；保留所有地址校验与固定目标连接，不添加
私有地址白名单、不固定 GitHub IP、不轮换出口规避配额、不修改用户全局 DNS/代理。
真实连接未解决的配置和网络步骤必须作为人工阻塞记录，不能以宿主机成功代替容器成功。
