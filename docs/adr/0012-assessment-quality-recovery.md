# ADR-0012 · V0.1.1 概念题质量与恢复

日期：2026-11-07。范围：Spec 10.1 / MVP 质量修复。

- 所有短测作答前在服务端清空 rubric；评分依据只在保存作答后展示，答案键不进入公开 DTO 或数据导出；未作答导出同样清空 rubric。
- 每次模型拟题仅尝试一次，不自动付费重试。FAILED/CANCELLED 可经显式授权和版本检查创建新任务；旧任务保持终态并撤销 lease。同一 Assessment 最多三次尝试（包括取消、旧版任务已经发生的尝试），超过上限需新学习会话。请求重放只返回其对应的当前任务，不覆盖答案。取消不能撤销供应商已接收的请求或保证退款；失败预留不退还。
- 选材顺序：请求选区/明确章节、会话选区、最近成功导学选区、目标关键词匹配、首个非空块。持久保存选材说明和实际有界片段，恢复使用相同材料；需要换范围则新建会话。选区必须逐字属于快照。证据主题跟随所选章节匹配的目标方向，不能固定归给目标首项；无匹配则保留章节名作为低强度候选。
- 仅作保守结构筛查：规范化去重、明显互相引用/全选选项及直接否定矛盾筛查；无法证明语义正确。引用匹配只证明快照含该文字，模型答案/解释不是独立验证；作答前后均要求人工复查，确认证据仍 LOW。
- 不增加数据库列；沿用 question JSON 和不可变历史 Job payload。0009→0010 往返只在空隔离测试库验证，保留旧来源边界题；回退概念题数据损失见迁移说明。
