# FrontierLearn 产品使用手册

先完成 [本地部署](LOCAL_DEPLOYMENT.md)，打开 <http://127.0.0.1:5176>。
第一次建议按 [两轮试用](FIRST_TRIAL.md) 走完；本页按实际页面说明全部现有能力。
页面里的“本地规则建议”和“模型解释/推测”有不同含义；阅读、收藏、导入、完成任务和
AI 回答均不能自动判定掌握。画像结论要查看证据强度、来源、时间和方法。

## 注册、登录、恢复与退出

入口：登录页“创建账号”。填写用户名和至少 12 字符密码 →“注册并保存恢复码”→
“下载恢复文件”→“进入学习空间”。预期出现左侧工作台导航；不需要 GitHub。
插件用同一账号密码登录即可共享资料，不会自动继承 Web Cookie。

再次使用选“密码登录”。忘记密码选“恢复账号”，输入用户名、恢复码、新密码；
下载新恢复文件，返回登录。恢复撤销全部旧会话并取消未完成作业。
Web“退出登录”退出当前 Web，插件“退出登录”只退出当前插件会话。
限制：没有邮箱找回/邮件验证；遗失密码和恢复码不能靠开启 Mock 找回正式账号。
浏览器扩展重启后可能需要重新登录，凭据不存网页 DOM。

## 学习目标

入口：左侧“学习目标”。填“想学会什么”、每日 5–240 分钟和可选的逗号分隔方向，
自评可以保持未知。需要顺序时展开“时间与先修方向”，添加“先学→再学”。
点“创建目标”后进入今日学习；已有目标可编辑、暂停或删除。
预期目标、时区、版本与方向保存，刷新仍在。
限制：先修关系是用户指定，不能解释为系统已验证的专业课程关系；删除目标会删除其计划历史，
独立知识来源与学习证据保留。

## GitHub 知识来源导入

入口：“知识来源”→“连接 GitHub 笔记”。填写仓库 URL/owner/repository、限定文件夹前缀，
勾选只读同意 →“添加只读来源”→“同步笔记”。“查看文件范围”检查每份文件和错误原因。
预期 Job 等待→运行→完成，记录提交 SHA、成功/失败文件，画像出现可追溯低强度线索。

公开仓库可以不配置凭据；私人仓库需要部署者先配置 [GitHub App](../production-integrations.md#github-app)，
然后在页面授权、安装/选择仓库与目录。ChatGPT 里的 GitHub 连接不会自动授权此应用。

限制：一个账号对同一仓库仅一个来源，最多五个目录前缀、200 份支持文件/10MB；
超限需缩小范围。支持 Markdown 和受限代码文本，不运行代码，不解析 ipynb/图片/二进制。
修改范围会取消当前同步，下次成功同步撤回范围外证据，不能轮流改范围累积整个大仓库。
坏文件记录失败并保留成功部分；限流/网络拒绝不代表导入成功，重试受预算和截止期限制。
可暂停/恢复/取消；“断开来源”可另行选择删除应用内正文及派生证据。

## 知识画像

入口：“知识画像”。搜索概念 →展开来源证据，查看 GitHub commit/路径/行号、摘录、
证据类型/方法/强度及时间，必要时记录有理由的人工修正。
预期能返回原始来源，阅读笔记仅为 OBSERVED_NOTE/EXPOSED/LOW。
限制：当前按标题、大写词和文件名规则提取；中英术语不自动合并，章节名可能不是好概念。
找不到 MQA/GQA 时保留未知，不把手工覆盖或 AI 解释当独立验证。

## 计划与今日学习

入口：“今日学习”选择目标，或从目标点“查看 / 生成计划”。
点击“生成学习计划”，查看长期方向、阶段任务、建议时间和推荐理由，再采纳任务。
根据页面按钮接受、完成、跳过、暂停、恢复、调整顺序或“插入临时兴趣内容”。
“查看计划历史”可查看与恢复旧版本；有新证据时点“根据最新证据重新规划”。
预期每次修改追加计划修订，保留原因/来源证据 ID，刷新后任务状态仍在。
限制：当前是明确标记的本地规则规划；不是模型生成的完整主题教程。
每日时间用于筛选当前目标任务；勾选完成只记录进度，不增加掌握证据。

## Chrome 插件、网页分析与阅读模式

入口：按部署手册构建/加载插件，在 arXiv 摘要/HTML 或 HF Model Card 页面点击工具栏图标。
点“分析当前页”，检查标题、解析范围、选区、来源片段与截断提示。
选择“直观解释”“深入原理”“工程实践”。点“回到原文 b…”检查高亮是否正确。
预览尚未发送到 API 或模型；选择目标/当前任务，勾选保存材料后点“保存并开启导学”。
预期 Worker 完成后出现阅读重点、先修线索、学习步骤和快照引用；Web“导学会话”能看到它。

限制：换域/换页需要重新点击工具栏授权；浏览器特殊页不允许注入。
摘要只代表摘要，PDF/登录墙/缺失正文用“使用手工粘贴文本”预览回退。
长文可能截断，图表/公式需在原页人工查看；“工程实践”只提供方法，不自动执行代码。
精确定位要求当前页内容和权限仍匹配；不匹配会明确提示，不能将快照匹配当独立事实核查。

## AI 导学、选区与追问

入口：插件保存会话后的导学区，或 Web“导学会话”打开历史。
追问时选“追问层级”“追问片段”，填写问题 →“保存追问”。
预期显示等待/运行/完成、可取消、失败时受限重试，历史刷新可继续。
会话关联的旧任务已不在当前计划时会提示，不能冒充仍是今日任务。

默认服务使用本地规则，只建议阅读方法，不会凭空回答概念问题。
真实 AI 需要部署者配置 OpenAI key/model，用户在“设置与数据”全局同意，
并在每次导学/追问另行勾选发送本次最小片段。预期模型内容标为“模型解释/推测”，需核验。
限制：本轮没有调用真实付费模型；最多 20 轮，预算按 UTC 日保守预留，失败不自动退还。
撤销授权会阻止迟到结果入库，不能保证供应商停算或退款。

## 理解验证、来源边界题与概念题

入口：已有成功导学的会话下方“开始短测”；历史在左侧“理解验证”复查。
默认来源边界题检查“原文支持”和“额外推断”。选 A/B/C 作答，阅读评价与限制，
再点“确认评价并加入学习证据”。预期作答不可覆盖，确认才写入 LOW 证据并修订关联计划。

模型概念题是可选路径：先配置模型和全局授权，选择拟题章节/片段，再勾选本次云处理并生成。
等待拟题 Job 完成后作答；作答前不展示答案键/rubric。
失败/取消后重新同意并点“恢复概念拟题（新任务）”；保留旧 Job，累计最多三次。
作答后复查评分说明、材料、选项和质量提示，再决定是否确认证据。

限制：来源题不是主题理解题；模型概念题是单道选择题，引用存在与结构筛查都不能证明答案正确。
答对仍 LOW/EXPOSED，不能评为熟练。真人判断、开放式解释/实践评价可靠性尚未完成。

## 笔记草稿、审核与下载

入口：完成短测后“生成笔记草稿”，或左侧“笔记审核”。
检查来源、当前理解、步骤、限制、未解疑问，编辑 Markdown →“保存草稿”。
“下载 Markdown，仅本地保存”可下载当前编辑内容；无需 GitHub。
预期草稿和版本留存，下载文件可独立使用；生成草稿不会发布。
限制：这是从评估结果产生的草稿，不是任意文档编辑器；编辑最多 50KB，自己补充的理解需人工核验。

## GitHub PR 写回

入口：“知识来源”连接真实 App 后单独授权非空笔记目录；
“笔记审核”展开“GitHub 分支与 PR”。
前提：服务端写回开关开启、完整 App/密钥配置、本人对所选仓库有写权限。

选择已授权仓库、目标 Markdown 路径和新建/手工合并模式 →保存草稿 →“预览 Diff”→
人工检查完整改动 →勾选审核确认 →“确认创建分支与 PR”。
预期只创建专用新分支/PR，由你在 GitHub 再审核合并。
手工合并将草稿视为完整目标文件，需自己把应保留的旧内容加回并重新预览，不能跳过 Diff。
合并后点“我已合并 PR，核对并重新索引”，只有实际同步到审核内容才追加计划修订。

限制：默认关闭，自动化仅模拟 GitHub 协议；本轮没有真实远端写回。
SHA/权限/目录变化时拒绝覆盖并保留草稿；响应丢失先核对已有 PR，不能无界重复创建。
撤销/应用内删除不会删除 GitHub 上已创建的文件、分支或 PR。

## 对话材料导入

入口：“导入对话”。选公开 ChatGPT 分享 URL 或手工粘贴；先预览、移除敏感内容，
确认范围后保存。文本可用“用户：/助手：”或“User: /Assistant:”标记角色。
预期显示角色、代码、AI 主张及候选问题；明确选择目标/当前计划后才加入或拒绝候选。
加入只追加任务修订，不更新掌握度；删除材料后历史计划仍可见但原文不可用。
限制：不绕登录墙/403/脚本依赖页面；真实在线分享页兼容性待验收。
失败记录可有限重试或新建粘贴回退，手工材料标记来源未经独立核验。

## 学习记录、权限与数据管理

| 入口 | 操作与预期结果 | 限制 |
|---|---|---|
| 今日学习→计划历史 | 查看版本、理由、恢复版本 | 历史恢复追加修订，不抹除后续历史 |
| 导学会话 | 打开同账号会话、继续追问、确认删除 | 删除清理其派生短测/草稿/证据；网页原文不受影响 |
| 理解验证 | 复查题目、答案、时间、评价和证据确认 | 作答不可覆盖，低强度结果不代表掌握 |
| 设置与数据→模型内容处理 | 同意/撤销后续云处理 | 已发生供应商处理无法撤回；默认不传完整私人文档 |
| 设置与数据→知识来源权限 | 暂停、撤销写权限、断开并选择清理范围 | 可保留已有证据；外部 GitHub 资源不被删除 |
| 设置与数据→后台任务与预算 | 查看状态、错误码、尝试次数，取消/有界重试 | 概念题恢复必须回短测重新同意；过期/超额不能通用重试 |
| 设置与数据→导出学习数据 | 下载我的学习记录 JSON，含正文/草稿/计划 | 上限 20MB/20,000 条；超限明确失败；不含凭据，不是数据库恢复备份 |
| 设置与数据→删除应用内全部数据 | 输入“删除我的数据”，再次确认后清除账号资料并退出 | 无法撤销，先导出；GitHub 文件/分支/PR 保留 |

遇到加载/拒绝/取消/失败，先记录入口、时间和错误码。点击页面提供的重试或重新检查，
不用清浏览器全部数据或重置数据库来掩盖问题。部署错误见 [故障排查](LOCAL_DEPLOYMENT.md#16-常见错误)。
