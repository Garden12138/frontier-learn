## 1. 北极星指标
**Verified Learning Progress**：一个用户在一定时间窗口内，通过有记录的验证，完成新知识点理解/应用的数量与质量（不能直接用 AI 自评作为唯一依据）。MVP 先使用“完成率 + 可复查验证记录 + 回访后的再测试”作为可解释代理指标。

## 2. 用户价值指标

| 层级 | 指标 | 定义/采集建议 |
|---|---|---|
| 进入学习 | Time to First Action | 初次导入/选择目标到用户开始第一项具体任务的时长 |
| 规划质量 | Plan Acceptance | 用户接受/编辑/拒绝计划的比例及原因 |
| 导学体验 | Useful Guidance | 用户点击“理解了/不理解/无帮助”、问题被解决的次数（辅助手段） |
| 学习成果 | Verified Task Completion | 完成题目、测验/实作并保存可查证记录的比例 |
| 连续性 | Evidence Reuse | 第二次计划可追溯地使用前次学习成果的案例比例 |
| 知识可携带 | Successful Writeback | 用户审核的草稿成功同步 PR/下载的比例；无未经授权写入 |
| 保持/迁移 | Follow-up Retention | 间隔后短测及项目迁移任务的完成情况（后续研究） |

## 3. 工程质量指标（门槛）

- 来源定位：结构化网页样本中的人工抽检引用锚点正确率目标 ≥95%；错误锚点不得当作真实引用。
- 幂等：同版本知识源重复同步、重复 PR 请求不产生重复副作用。
- 数据安全：跨 user_id 数据访问必须被拒绝；公开页面文本不得执行系统工具指令。
- 可恢复：外部连接超时、PR 冲突、模型失效均保留任务与草稿状态。
- 性能：缓存 Web 首屏 p95 目标 <3 秒；导入异步，LLM 等待状态可见（目标值在真实压测后校准）。
- 可管理：每个外部连接均支持暂停/断开，内部学习数据具备导出/删除操作。

## 4. 用户研究与实验计划

1. **可用性任务**：给 5–10 名目标开发者（初期小样本，不作统计显著性承诺），请其从一篇陌生论文开始，记录第一次可执行行动所需时间。
2. **个性化对比**：对相似材料比较“通用摘要导读”和“基于知识证据的导读”，采用随机或交叉顺序；测理解/应用任务，而不是仅问满意度。
3. **证据误判审计**：抽样比对知识等级与来源事实，特别检查“读过=掌握”问题。
4. **闭环验证**：至少两次连续会话，第一次测验→学习记录→第二次计划变化解释。
5. **回写安全演练**：无权限、版本冲突、分支被删、API 限流、网络中断、重复确认，所有异常下必须保留草稿。
