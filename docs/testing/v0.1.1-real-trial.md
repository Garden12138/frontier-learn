## Mac 本地启动

以下命令从仓库根目录运行；需要 Docker Desktop/OrbStack 已启动。升级既有真实资料库前先备份，停止 API/Worker，再部署匹配迁移；本轮未修改既有开发数据库。

```sh
pnpm install --frozen-lockfile
FRONTIER_DB_PORT=55433 FRONTIER_API_PORT=18000 docker compose -f infra/docker-compose.yml up -d --build --wait
FRONTIER_API_PROXY=http://127.0.0.1:18000 pnpm dev
```

Web：<http://127.0.0.1:5173>；API 健康：<http://127.0.0.1:18000/api/v1/health>；数据库就绪：<http://127.0.0.1:18000/api/v1/ready>。在第二个终端构建插件：

```sh
FRONTIER_EXTENSION_API_ORIGIN=http://127.0.0.1:18000 pnpm --filter @frontier/extension build
```

Chrome 打开 `chrome://extensions`，启用开发者模式，加载 `apps/extension/.output/chrome-mv3`。后端端口变化时须重建并在 Chrome 重新加载。日常试用关闭 Mock、外部写回和云模型，不需要私人凭据。

停止并保留数据：Web 终端 `Ctrl+C`，再运行 `docker compose -f infra/docker-compose.yml stop`。不要删除数据卷。

## Web 与真实笔记试用

1. 注册独立账号，下载恢复码；插件使用同一账号登录，登录授权与 GitHub 授权分开。
2. 建立目标“理解 Self-Attention，并进一步学习 MHA、MQA、GQA”，每天 30 分钟。方向可填“自注意力、MHA、MQA、GQA”；先生成计划并保存当前推荐理由。
3. 在知识来源连接公开仓库 `https://github.com/Garden12138/notes`，只读路径设为 `ai/book_note/Build-A-Large-Language-Mode notebook/`。不要误填 URL 编码的 `%20`，文件夹名保留空格。
4. 同步后检查文件范围、提交 SHA、行号和证据类型；笔记、代码仅为接触线索，不能标成掌握。重新同步同一 SHA 应保持幂等。
5. 若出现 `GITHUB_RATE_LIMIT`，保留失败记录，等待额度恢复后在截止期内受限重试，过期则发起新同步；不使用私人 token 绕过限制。11-07 首次和 11-08 额度重置后的重试均为该失败，31 份目录完整在线同步未通过。需在有可用公开 API 配额的网络环境重放，或通过产品正常 GitHub App 授权后再验收；不要在聊天中提供私人 token。
6. 整库清点有 1,145 份受支持文件，超过 200 份/10MB 单次上限；目标目录为 31 份、420,382 bytes。超限会明确报错而非截取前 200 份。更大资料集按互不重叠的子目录创建独立来源分批同步；单个来源最多五个前缀。修改同一来源范围会撤销范围外证据，不能用它伪装累计导入。`.ipynb`、图片与二进制不在当前支持范围。
7. 查看画像中的实际候选与错误：标题是低强度线索；“长序列建模的问题”“本节实践代码(整合版)”等章节不是干净的概念名称，代码文件名候选也不等于概念。当前规则不会自动对齐 Self-Attention/自注意力和 MHA/多头注意力，MQA/GQA 未出现时应保留未知。
8. 重新生成计划，对比来源证据 ID 与“已有笔记，先解释验证”的理由，不仅比较任务措辞。

## 插件阅读、短测及草稿

1. 打开 <https://arxiv.org/abs/1706.03762>、<https://arxiv.org/html/2401.04088v1> 或 <https://huggingface.co/openai-community/gpt2>。点击工具栏后再点“分析当前页”；预览范围和引用，不会自动上传。
2. 摘要页只代表摘要。选取原文，再分析/保存，或在短测“拟题章节”明确选择章节。关联 Web 上的目标/当前任务，确认保存材料。
3. 查看“本地规则建议”；未配置/未双重授权时提供阅读方法。真实模型解释需要服务端配置和每次允许上传，不因全局授权自动发送。配置见 [接入文档](../production-integrations.md)，本轮未获付费授权，不能据 Fake 宣称真实解释质量通过。
4. 追问时选片段与层级，点击定位引用。换域后重新点击工具栏；原页内容变化、权限失效或历史任务不在当前计划中时必须看到明确提示。Web“导学会话”能继续同一记录。
5. 默认“开始短测”是来源边界题。可选概念题须配置云模型、全局同意和本次同意；发送主题与最多 1800 字符片段。作答前看不到 rubric、答案键或评分依据，数据导出也不能泄露。
6. 观察 PENDING→RUNNING→SUCCEEDED 后再作答。失败或取消后，重新勾选同意再点“恢复概念拟题（新任务）”：保留 Assessment、追加不同 Job，每份短测累计最多三次。失败预留不退还；取消不能保证供应商停止或退款。旧任务不会恢复，也不能用通用 Jobs retry 绕过授权。
7. 先尝试取消/恢复，再完成作答；重复提交同一答案保持幂等，不能改写已保存答案。作答后显示 rubric、模型答案依据、限制和人工复查提示。引用匹配与模型自评不能证明选项语义正确。
8. “确认评价并加入学习证据”后才更新计划，仍为 LOW/EXPOSED。生成笔记草稿、下载 Markdown，在 Web“笔记审核”编辑并检查来源、限制、未解疑问。本轮只下载，不执行远程写回。
9. 第二轮生成计划，查看前次测验 ID/证据关联：正向概念题应继续独立解释/举例，负向结果应复查；不能直接跳到掌握或无限重复同一题。
