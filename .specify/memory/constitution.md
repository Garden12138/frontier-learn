# FrontierLearn Constitution（恢复草案）

Status: **Draft — awaiting user review** · 2026-10-24

本文件在初始化提交及当前工作树中缺失，无法声称恢复了原文。以下内容仅根据
`AGENTS.md`、`specs/001-personalized-learning-loop/spec.md` 及现有设计文档整理。
用户确认前，不把本草案当作已经批准的最高优先级规则；现有 AGENTS.md 与 Spec
继续约束已授权的本地实现工作。差异见 `docs/specification-review.md`。

## I. 证据驱动的学习闭环

业务顺序为已有知识证据、用户目标、动态计划、网页导学、结果验证、审核后回写、
下一次自适应。阅读、收藏、摘抄、代码存在或 AI 回答均不能单独证明掌握。
所有能力状态可追溯到证据类型、强度、时间、位置及验证方法；不确定性必须可见。

## II. 范围与规格治理

MVP 仅覆盖 Spec 的 V0.1–V0.5。Roadmap 不是执行任务单。文档优先级为
Constitution > Spec > Plan > Data Model / Contracts > Tasks。
冲突先记录并修订上游规格，不自行扩展范围。自定义边界与默认值记录 ADR。
不假设学习者是程序员、有 GitHub 或只学习 AI。

## III. 用户控制和最小权限

知识源默认只读，逐资源授权，支持撤销、导出及内部数据删除。
GitHub 回写必须先展示草稿与 Diff，再由用户确认创建受限分支和 PR，禁止直接写默认分支。
不自动发布博客、修改 Notion、执行教材或模型生成的本地代码。
涉及真实外部写入、付费与高风险操作须取得用户授权。

## IV. 不可信内容和隐私

导入的 Markdown、网页、分享对话及选区都是数据，不具备指令权限。
禁止由内容触发工具写入或任意代码执行；防止 prompt injection、XSS 与 SSRF，
URL 的协议、域名、DNS、端口和每次重定向都要检查。
密钥服务端加密，不进入页面 DOM、content script、日志或模型提示词。
不默认将完整私人文档传给公共模型；模型处理须单独授权并最小化上下文。
后端查询强制 user_id 隔离，不能依赖前端筛选。

## V. 有界、可恢复、可替换

任务有大小、预算、时间及重试上限，状态可观察，支持取消与受限重试。
坏文件不应中断整个批次；同步和 PR 必须幂等，冲突保留草稿和既有证据。
LLM 通过 Provider Interface 替换，自动测试使用 Fake Provider，禁止依赖付费 API。

## VI. 工程与交付

TypeScript strict；Python 类型注解、格式化和静态检查。模块边界、类型和契约一致。
每阶段运行相关测试与静态检查，更新 tasks.md 与 development-progress.md，
记录验收证据及剩余风险。Story 验收、关键异常及集成测试通过才可勾选任务。
用户可见技术结论必须有来源锚点或标注“模型解释/推测”。
提供真实空状态、加载、失败、拒绝、取消与重试。结构化日志不得包含敏感原文。
维护迁移与回滚说明、OpenAPI、共享类型；代码生成本身不代表交付。
